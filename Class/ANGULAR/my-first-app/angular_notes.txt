Types of Directives in Angular

Angular mainly has two important directives:

Structural Directives
Attribute Directives
1. Structural Directives

Structural directives are used to change the structure of the webpage (DOM).
They can add, remove, hide, or repeat HTML elements.

Examples:
*ngIf → Show or hide element
*ngFor → Repeat elements in loop
*ngSwitch → Multiple conditions
Example:
<p *ngIf="isLogin">Welcome</p>

If condition is true → show paragraph
If false → remove paragraph

Definition:

Structural directives modify the layout of DOM by adding or removing elements.

2. Attribute Directives

Attribute directives are used to change the appearance or behavior of an existing HTML element.

They do not add/remove element, only change style, color, class, etc.

Examples:
ngClass → Add/remove CSS classes
ngStyle → Apply styles
ngModel → Two-way data binding
Example:
<p [ngStyle]="{'color':'red'}">Hello</p>

Text color becomes red.

Definition:

Attribute directives change the look or behavior of an element without changing structure
